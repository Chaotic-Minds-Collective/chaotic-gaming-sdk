# Chaotic Gaming SDK

Shared TypeScript contracts for the Chaotic Gaming Core API, integrations, and event consumers.

## Scope
- Stable API response and error envelopes
- Player and linked-account DTOs
- Service integration contracts
- Versioned event envelope
- No runtime credentials or direct database access

## Development
Run `npm install`, `npm run typecheck`, and `npm run build`. Package publication is intentionally not configured; consume from Git or a future approved package registry.
